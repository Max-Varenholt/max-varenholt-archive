# Max Varenholt Archive

Experiencia web narrativa y satírica construida alrededor del archivo improbable de Max Varenholt.

## Estructura

- Las páginas HTML funcionan como resultados, noticias, perfiles y documentos independientes.
- `assets/lore/` contiene únicamente los recursos visuales preparados para la web.
- `_worker.js` controla el modo público/cerrado cuando el sitio se publica en Cloudflare Pages.
- `/control` es el panel privado de activación para móvil.

## Privacidad

Este repositorio no debe incluir fotografías originales, credenciales, claves de administración, copias de seguridad ni información profesional real. La clave del panel se configura exclusivamente como secreto del proveedor de alojamiento.

## Publicación

El sitio está preparado para Cloudflare Pages con repositorio privado. No necesita proceso de compilación: el directorio de publicación es la raíz del repositorio.
